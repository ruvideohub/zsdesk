# Этап P0: защита профилей — текущий объём

Этот документ фиксирует частичную реализацию A1 и A2 из `code-audit-019aadf.md`, а не закрытие всего этапа P0.

## Fences

- При отсутствии `desktop-fences.json` создаётся профиль по умолчанию. При ошибке чтения, невалидном JSON или размере более 16 МиБ запуск host останавливается до создания окон и действий со значками; в сообщении указан путь к исходному файлу. Файл не удаляется и не перезаписывается.
- При сохранении существующий профиль повторно проверяется; новый записывается в уникальный временный файл и заменяется атомарным helper. Это защищает от порчи профиля между запуском и обычным сохранением, но проверка и замена не являются транзакцией между независимыми писателями. Нужна отдельная межпроцессная синхронизация host/watchdog и тест на гонку.
- Watchdog теперь сообщает об ошибке чтения вместо того, чтобы считать невалидный профиль пустым. Если профиль повреждён во время работы, watchdog **не может надёжно определить**, кто скрыл значки; он не меняет их вслепую. При необходимости пользователь может включить «Показать значки рабочего стола» через меню Windows и восстановить файл из своей копии. Автоматическое восстановление для повреждённого маркера и отдельный надёжный recovery-маркер ещё не реализованы; автоматической резервной копии в этом изменении нет.

## Dock

- Старый `%APPDATA%\ZSDesk\Dock` копируется в уникальную соседнюю временную папку; только после завершения копирования файлы становятся новым `%APPDATA%\AuraUI\Dock` посредством перемещения без замены существующей папки на Windows. Исходник, включая файл заметок, не удаляется. Копируются обычные файлы непосредственно в корне, как и прежде.
- При ошибке копирования/публикации приложение показывает ошибку и не создаёт новый профиль по умолчанию; повторный запуск может повторить миграцию. Если целевая папка уже существовала до начала, она не изменяется. Папки, частично созданные **старой** реализацией, автоматически не объединяются — их надо проверять вручную, не перезаписывая новый профиль. После аварийной остановки временная папка может остаться, но она не блокирует повтор и автоматически не удаляется при следующем запуске.
- Watchdog панели задач запускается независимо от миграции, чтобы ошибка профиля не мешала восстановлению панели задач.

## Проверки и незавершённая приёмка

Выполнены переносимые unit-тесты, включая повреждённый профиль Fences, неуспешное копирование с последующим повтором и существующий destination; четыре статические проверки репозитория. Минимальный Windows GNU harness проверяет компиляцию нового MoveFileW и сообщения об ошибке, не всё приложение. Попытка полного cross-check остановилась на зависимости `windows` из-за ограничений среды и не проверила приложение целиком.

Перед выпуском обязательны Windows CI и изолированные сценарии: locked/access-denied, авария на каждом шаге сохранения/миграции, два одновременных процесса, авария host/потока во всех состояниях иконок, восстановление с битым/отсутствующим профилем, старые частично созданные папки и обновление с сохранением закреплений. Проверить исходно скрытые пользователем значки — решение не должно менять их состояние без надёжного признака владения. Не распространять сборку как готовую до этих проверок.
