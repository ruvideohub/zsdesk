# Панель: что она делает и чем должна быть

Это разбор функциональности панели, а не описание API. Он нужен, чтобы не добавлять виджеты
по одному и не терять смысл: у панели три работы, и сейчас они перемешаны.

## Что есть сейчас

| Слой | Сколько | Где |
|---|---|---|
| Каталог виджетов | ~40 определений | `crates/aura-dock/src/widgets/catalog.rs` |
| Быстрый список в меню панели | 9 | `DOCK_WIDGETS` в `dock.rs` |
| Категории в галерее | 8 | `Category` в `catalog.rs` |
| Пунктов в контекстном меню панели | 20+ | `context_menu` в `dock.rs` |
| Отдельных поверхностей | 6 | панель, Launchpad, центр управления, шторка меню, превью, стек |

Три работы панели:

1. **Запуск** — закреплённые приложения, Launchpad, поиск. Это получается хорошо.
2. **Статус** — «что происходит»: батарея, сеть, «сейчас играет», ресурсы. Получается хуже:
   каждый статус — отдельный виджет, который надо самому найти и поставить.
3. **Управление** — «сделай так»: Wi-Fi, звук, яркость, тема, ночной свет. Здесь сейчас три
   конкурирующих ответа на один вопрос.

## Что не так

- **Дубликаты.** `quick-toggles` (Wi-Fi, Bluetooth, тема, mute), `control-tiles` (тема, mute,
  ножницы, блокировка), `dark-mode`, `focus`, `notifications`, `connectivity` и центр
  управления — пять-шесть способов переключить одно и то же. Пользователь не знает, какой из
  них «настоящий», а состояние приходится синхронизировать между ними.
- **Открытие центра управления спрятано.** Пункт контекстного меню — не кнопка: без чтения
  меню шторку не найти. Исправлено в этом раунде: на панели стоит виджет `control-center`.
- **Меню — склад.** 20+ пунктов, из которых повседневных три («Настройки панели», «Виджеты»,
  «Выйти»). Всё остальное — редкие операции, которым место в настройках.
- **Статус не читается с одного взгляда.** Чтобы узнать заряд и сеть, нужно поставить батарею
  и сеть отдельными виджетами; на узкой панели они вытесняют приложения.
- **Виджеты-заглушки.** Часть каталога открывает параметры Windows (`windows-settings`,
  `windows-update`, `focus`, `run`) — это не виджеты, а ярлыки, и они занимают место в галерее
  рядом с настоящими.

## Чем должна быть панель

Три зоны, каждая со своей ролью:

```
[ Launchpad ][ приложения … ]        [ статус: сеть · батарея ][ ⌃ центр управления ]
   запуск                              статус                    управление
```

1. **Слева — запуск.** Launchpad, закреплённые приложения, стеки, разделители. Ничего
   системного: ни часов, ни батареи, ни переключателей.
2. **Справа — статус, один блок.** Три-четыре мелких индикатора (сеть, звук, батарея,
   играет/пауза) впритык, как в строке меню macOS. Клик по любому — открывает центр
   управления, потому что подробности там.
3. **Управление — только центр управления.** Одна шторка с плитками и ползунками. Виджеты
   `quick-toggles`, `control-tiles`, `dark-mode`, `connectivity` из каталога убираются: их
   работа уже сделана, дважды.

Правила, по которым это живёт:

- **Состояние читается, а не дублируется.** Всё, что показывает или меняет систему, спрашивает
  одно место (`ControlState`, `Hub`) и пишет в него же. Ни один виджет не хранит свою копию
  Wi-Fi, яркости или темы.
- **Один виджет — один факт.** «Часы» — время. «Погода» — погода. Виджет, который открывает
  параметры Windows, — не виджет.
- **Виджет на панели — только то, что нужно каждый день.** Всё остальное живёт в Launchpad.
- **Меню — три пункта плюс настройки.** «Настройки панели…», «Виджеты…», «Выйти». Действия
  вроде «Показать рабочий стол» — плиткой в центре управления, а не пунктом меню.

## Порядок работ

Сделано в этом раунде:

- [x] Кнопка центра управления на панели (`control-center`), появляется сама, снимается галочкой.
- [x] Шторка читается на белом фоне (плотная карточка, рамка).
- [x] Яркость: ползунок показывает то, что запрошено; одна запись за раз; честное
      «Not supported», если монитор не понимает DDC/CI.
- [x] Увеличение под курсором не дёргается: пик прилипает к слоту.

Дальше, по убыванию пользы:

1. **Блок статуса справа** — новый виджет `status-strip` (сеть · звук · батарея · играет),
   клик открывает центр управления. Заменяет три отдельных виджета на панели.
2. **Убрать дубликаты из каталога** — `quick-toggles`, `control-tiles`, `dark-mode`,
   `connectivity`; их плитки уже есть в центре управления. Вместе с ними уходят и три записи
   в `DOCK_WIDGETS`.
3. **Меню панели до трёх пунктов** — «Настройки панели…», «Виджеты…», «Выйти»; редкое
   (перезапуск Explorer, сброс кеша значков, измерение) — на вкладку «Дополнительно» в
   настройках.
4. **Категории галереи по работе, а не по типу** — «Время», «Погода», «Система», «Медиа»,
   «Мониторинг», «Заметки»; ярлыки Windows — в отдельную группу «Ярлыки» и не в быстром списке.
5. **Память раскладки** — панель запоминает ширину и набор виджетов на монитор, а не на
   профиль (сейчас ноутбук с внешним экраном переставляет всё на обоих).
6. **Жест «потянуть вверх» на панели** — открывает центр управления, как в Windows 11; для
   этого хватает уже существующего `takes_drag`.

Пункты 1–3 меняют то, что видит пользователь, поэтому их стоит делать одной серией, а не
по одному: иначе полпути выглядит как «часть виджетов пропала».
