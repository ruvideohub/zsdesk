# Панель AuraDock (док + Launchpad)

Панель внизу экрана — **Laminar Dock** (`davesousa/Laminar_Dock`, MIT, © 2026 Dave Sousa),
взятый в исходниках и приспособленный для AuraUI. Вместе с ним в поставку входит `laminar-sys` —
системный слой (приложения, поиск, звук, медиа, радио, тема, статистика).

| Что | Где |
|---|---|
| Панель, трей, стеки, превью, поиск, Launchpad | `crates/aura-dock` |
| Системные сервисы панели | `crates/laminar-sys` |
| Владелец запуска панели и Fences | `auraservice.exe` |
| Настройки панели | `%APPDATA%\AuraExplorer\Dock\config.json`; страница — `AuraDock.exe --settings` |
| Установщик полного набора | `packaging/windows/aura.iss` + `packaging/bundle.json` |
| Лицензия апстрима | `packaging/licenses/Laminar-MIT.txt` |

## Один установщик, централизованный запуск

1. `packaging/bundle.json` включает отдельные `AuraDock.exe`, `Fences.exe` и `auraservice.exe`;
   `scripts/package.ps1` собирает и раскладывает их в один проверенный набор.
2. При обычном запуске AuraExplorer вызывает `service_start::ensure_running`, который запускает
   только `auraservice.exe --run`. Сама программа не создаёт процесс панели или Fences.
3. AuraService по переключателям запускает Fences и AuraDock и владеет общей записью входа в
   Windows. Настройки этих переключателей открываются через `auraservice.exe --settings`.
4. `widgets.exe` пока остаётся дочерним процессом AuraDock; выделение виджетов в самостоятельный
   сервисный компонент — отдельная будущая задача. Завершение панели завершает и её виджеты.

В меню AuraExplorer и Fences есть переход к общему окну «Запуск и компоненты». В standalone
Fences-установке без соседнего AuraService сетки используют собственную необязательную настройку
запуска при входе; интегрированный пакет оставляет владельцем запуска службу.

## Что изменено относительно апстрима

| Место | Изменение |
|---|---|
| `launchpad.rs` | одна тихая панель по центру вместо трёх (виджеты и центр управления выключены), подложка светлее (`scrim 0.22`) |
| `updater.rs` | Velopack вырезан: панель обновляется вместе с AuraUI-набором, `installed() == false`, запуском в комплекте владеет AuraService |
| `config.rs` | каталог настроек `%APPDATA%\AuraExplorer\Dock`, `check_updates` по умолчанию выключен |
| `main.rs`, `dock.rs`, `tracker.rs` | имена окна, класса и мьютекса — `AuraExplorer.Dock` / `AuraExplorerDock`, меню говорит «AuraDock» |
| `Cargo.toml` | пакет `aura-dock`, версия как у AuraExplorer, зависимости — только `windows`, `windows-core`, `windows-numerics`, `serde`, `serde_json`, `laminar-sys` |

## Русский интерфейс

Подписи панели — русские. Переводятся два места, через которые проходит весь текст:
`menu::MenuItem::item/header` (все меню: панель, значки, виджет часов, уведомления) и
`launchpad::Launchpad::txt` (всё, что рисует Launchpad: вкладки настроек, подписи, подсказки).
Таблица лежит в `crates/aura-dock/src/strings.rs` и сопоставляет **целые строки**, поэтому
имена приложений, пути, имена файлов и текст пользователя остаются как есть. Подписи с
числами («Закрыть все окна (3)», «Все приложения 12») обрабатываются по префиксу.

Язык задаётся в `config.json`:

| `language` | Что получается |
|---|---|
| `"ru"` (по умолчанию) | русский |
| `"en"` | английский апстрима |
| `"auto"` | русский, если интерфейс Windows русский (`GetUserDefaultUILanguage`), иначе английский |

## Что убрано из апстрима

- **Виджеты и коннекторы.** Колонки виджетов в Launchpad, галерея виджетов, центр
  управления, а вместе с ними секция «Виджеты» в настройках и подключения (GitHub,
  календарь, аналитика, погода) больше не показываются и недоступны из интерфейса.
- **«О программе»** — секции в настройках панели нет; версия и обновления и так видны
  в меню панели. Осталось три вкладки: «Панель», «Стекло», «Поведение».
- **Три панели Launchpad** — см. ниже.

## Значок AuraExplorer на панели

На панели закреплена иконка AuraExplorer **первой слева**; она появляется на любом профиле: `apps::ensure_own_pin` при старте панели сверяет `pins` с `AuraExplorer.exe`, лежащим рядом с
`AuraDock.exe`, и добавляет иконку с разделителем, если её нет. Картинку и подпись
отдаёт сама оболочка (иконка берётся из ресурсов `AuraExplorer.exe`), поэтому отдельный файл
значка не нужен. Клик открывает файловый менеджер; сетки запускаются через AuraService или ярлык Fences.

## Значок панели

У `AuraDock.exe` есть свой значок и блок версии — иначе в Проводнике, в меню «Пуск» и в
списке установленных программ вместо панели показывалась бы безымянная системная иконка.

- `crates/aura-dock/resources/aura-dock.ico` — панель в том же золоте, что папка
  `AuraExplorer.exe`: скруглённая полоса с тремя плитками. Размеры 16…256, каждый нарисован
  отдельно с 4-кратным запасом, поэтому 16 и 20 px читаются, а не превращаются в кашу.
- `crates/aura-dock/resources/aura-dock.rc` — иконка `101 ICON` и `VERSIONINFO`
  (`AuraDock`, 0.3.23, MIT и упоминание Laminar Dock).
- `crates/aura-dock/build.rs` — встраивает `.rc` через `embed-resource` (тот же приём,
  что у `aura-explorer`; манифест панели не нужен, поэтому `manifest_optional`).
- `scripts/make-icons.py` — перерисовывает `.ico` из кода: `python3 scripts/make-icons.py`.

## Установка и автозапуск

`packaging/windows/install.ps1` (и `install.cmd` для двойного щелчка) ставит AuraExplorer в профиль
пользователя — администратор не нужен:

1. сверяет файлы с `manifest.json` (версия и sha256 каждого) — подменённый или недокачанный
   архив не установится молча;
2. копирует весь набор в `%LOCALAPPDATA%\Programs\AuraExplorer`, снимает метку «из интернета»
   (`Unblock-File`), подхватывает рядом лежащие DLL Visual C++ Runtime;
3. прописывает автозапуск в `HKCU\…\CurrentVersion\Run`: `"…\auraservice.exe" --run` — одна
   запись на всё; что именно поднимает служба, решают её переключатели;
4. делает ярлыки в меню «Пуск»: «AuraExplorer» (обычный запуск) и «AuraUI — запуск и
   компоненты» (`auraservice.exe --settings`);
5. запускает службу и печатает состояние подписи.

Отдельной записи автозапуска для панели нет намеренно: владелец запуска один — служба. Вторая
запись дала бы вторую панель, которая дерется за место на экране с первой. Панель, сетки и
виджеты включаются и выключаются переключателями в окне «AuraUI — настройки и запуск».

Прочее: `-NoAutostart` — не прописывать автозапуск, `-DesktopShortcut` — ярлык на рабочем
столе, `-NoStart` — не запускать после установки, `-Remove` — удалить всё (процессы,
автозапуск, ярлыки, папку). В Inno-установщике (`packaging/windows/aura.iss`) то же самое
делает задача «autostart» с записью в `[Registry]` и `uninsdeletevalue`.

## Виджет часов на рабочем столе

`crates/aura-dock/src/desktop_clock.rs` — стеклянная карточка на рабочем столе: время
крупным тонким шрифтом, под ним дата и день недели по-русски («четверг, 19 ноября»).
Windows Composition рисует её той же поверхностью, что панель и Launchpad.

**Карточка сама себе настройки** — правый клик по ней открывает меню:

| Пункт | Что делает |
|---|---|
| Угол: верхний левый / правый, нижний левый / правый | куда поставить карточку |
| Размер: компактный / обычный / крупный | множитель 0.85 / 1.0 / 1.2 |
| 24-часовой формат | 12 часов с AM/PM вместо 24 |
| Показывать дату | без даты карточка ниже (96 вместо 132) |
| Показывать секунды | тогда карточка перерисовывается каждую секунду |
| Убрать часы | `desktop_clock: false` |

- Карточку можно **перетащить** мышью: пока тянешь — она остаётся на своём мониторе, а при
  отпускании прилипает к ближайшему углу.
- Окно **не** topmost и не забирает фокус (`WS_EX_NOACTIVATE`), поэтому лежит над обоями и
  под окнами приложений — как виджеты рабочего стола в macOS. Клики по самой карточке она
  забирает (иначе её нельзя было бы ни перетащить, ни настроить), всё остальное проходит мимо.
- Карточку можно **поставить куда угодно**: после перетаскивания она остаётся там, где её
  отпустили (`clock_pos`, физические пиксели монитора; при выходе за край прижимается), а не
  прыгает в ближайший угол. Пункты «Угол: …» — готовые положения, они сбрасывают свободную
  позицию.
- «Lock Position» (`clock_locked`) закрепляет карточку: перетаскивание ничего не делает, меню
  по правому клику работает.
- «Убрать часы» в меню карточки выключает `desktop_clock`, а вернуть их можно из меню панели —
  «Clock on the Desktop». Раньше обратной дороги не было.
- Настройки: `clock_corner` (`top-left`…`bottom-right`), `clock_pos`, `clock_locked`,
  `clock_scale`, `clock_12h`, `clock_date`, `clock_seconds` и сам `desktop_clock` в
  `config.json`; меню пишет их сразу.
- Создаётся только основной панелью, не вспомогательными на других экранах.

## Виджеты на самой панели

Виджеты — не только карточки Launchpad: любой из каталога
(`crates/aura-dock/src/widgets/catalog.rs`) можно поставить прямо на панель, слева от иконок.

- **Добавить:** правый клик по панели → раздел «Виджеты на панели»: девять повседневных
  (часы, погода на сегодня, календарь, монитор ресурсов, батарея, «сейчас играет», сеть,
  быстрые действия, центр управления) с галочкой у тех, что уже стоят. «Другие виджеты…»
  открывает галерею Launchpad — там весь каталог, и любой виджет можно перетащить на панель.
- **Убрать:** там же снять галочку, либо правый клик по самому виджету → «Убрать с панели»
  (в том же меню — размер S/M/L и настройки виджета). Пунктов «Показать в Launchpad» и
  «Другие виджеты…» больше нет: виджетов в Launchpad нет, и оба пункта вели в никуда.
- Панель хранит их в `pins` как `{ "widget": "clock" }`, поэтому порядок, разделители и стеки
  работают как обычно, а жесты перетаскивания внутри панели — тоже.

## Чего больше нет

- **«О программе»**: ни в меню AuraExplorer, ни в настройках панели. Окно панели поиска и
  подсказок по клавишам осталось, но пункта, который открывал «О программе», нет.
- **Проверки обновлений**: стартовая ежедневная проверка не запускается, уведомление о
  новой версии не показывается, в меню панели нет «Проверить обновления…». Обновления
  ставятся только установщиком, вручную.

## Подпись сборки

GitHub Actions подписывает оба exe на каждом прогоне (`scripts/sign.ps1`): если в секретах
репозитория лежит настоящий сертификат (`AuraExplorer_SIGN_PFX_B64` и `AuraExplorer_SIGN_PFX_PASSWORD`),
подпись ставится им; если нет — одноразовым самоподписанным сертификатом, чтобы в файле была
валидная подпись Authenticode (`Get-AuthenticodeSignature` её видит и её можно явно
доверить). SmartScreen предупреждение снимает только настоящий сертификат.

## Launchpad

Открывается иконкой сетки на панели, клавишей Windows (если включено) или из меню.

- **Одна панель**: около 70 % экрана по ширине (не шире 1180 pt) и не выше 820 pt, стоит по центру
  над панелью, никогда не упирается в док.
- **Сверху поиск** по приложениям, настройкам, файлам и калькулятору.
- **В середине сетка**: закреплённые, «All apps» — всё, что видит оболочка, с прокруткой.
- **Внизу** — только пользователь, настройки и питание; в настройках три вкладки:
  «Панель», «Стекло», «Поведение».
- Никаких колонок виджетов, центра управления, галереи виджетов и интернет-поиска: они остались
  в апстриме (`render_left`, `render_right`, `launchpad_widgets.rs`, `launchpad_search.rs`), но
  не рисуются и не принимают клики.

## Панель задач

`hide_windows_taskbar` по умолчанию **включён**: панель занимает место панели задач Windows, а
сторож (`taskbar.rs`) возвращает её на место при любом выходе панели — штатном, аварийном или
при завершении AuraExplorer. Выключить можно в настройках панели (правый клик по фону → Settings).

### Часы и z-порядок

Карточка часов — обычное (не topmost) окно, но она ещё и **не поднимается**: при
позиционировании она вставляется в z-порядок сразу под окно, которое сейчас активно
(`GetForegroundWindow`, если это не рабочий стол и не собственное окно панели), и раз в секунду
(на тике часов) проверяет, не сменилось ли переднее окно. `SetWindowPos` с
`hWndInsertAfter = null` — это `HWND_TOP`, именно он раньше и поднимал карточку над всеми
окнами при смене настроек и перетаскивании. Перетаскивание идёт с `SWP_NOZORDER`.

## Увеличение под курсором

Иконки растут по косинусной кривой вокруг «пика» — точки, к которой привязано увеличение.
Пик **прилипает к центру слота** под курсором (`Geo::center_abs`, `Dock::anchor_x`), а не
едет за мышью попиксельно: пока курсор остаётся над той же иконкой, `PointerX` не меняется
вовсе, шестерня раскрывается один раз (анимация `Amount`, 160 мс) и замирает. Переход на
соседнюю иконку — один шаг, как в macOS.

Почему так: раньше `PointerX` писался на каждое сообщение `WM_MOUSEMOVE`, а попадание
считалось по **увеличенной** раскладке. Пока шла анимация, сдвиг `Acc` уводил под курсор
соседнюю иконку — попадание перескакивало туда-обратно на каждом кадре, и панель дёргалась
(подпись, превью и подсветка мигали). Теперь попадание считается по неподвижной, не
увеличенной раскладке (`Geo::hit_base`), а всё, что рисуется над панелью (превью, стек,
подпись, попадание в виджет), берёт `anchor_x` — ту же точку, по которой посчитана картинка.

## Центр управления

Одна стеклянная шторка над панелью (`crates/aura-dock/src/control_center.rs`), разделённая
на секции сверху вниз:

- **Плитки** 3×2: Wi-Fi, Bluetooth, режим полёта, ночной свет, «не беспокоить», тёмная/светлая
  тема. Включённая плитка подсвечивается цветом своего акцента.
- **Ползунки**: звук (и кнопка «без звука»), микрофон (в Windows есть только выключение, поэтому
  это переключатель), яркость (DDC/CI).
- **Сеть**: текущая сеть или их число, по клику раскрывается список видимых сетей с уровнем
  сигнала, замком и кнопкой подключения к незанятой.
- **Сейчас играет**: обложка-заглушка, название, исполнитель, «назад / играть / вперёд».
- **Подвал**: батарея (процент, зарядка, остаток времени) и значки трея — клик по значку уходит
  в само приложение, как в области трея.

### Кнопка на панели

Центр управления — обычный виджет каталога (`control-center`, `ToolKind::ControlCenter`): на
панели это плитка с шевроном вверх (`WAct::ControlCenter`), клик открывает шторку, повторный —
закрывает. Он стоит на панели **сразу**: при старте панель вызывает
`Config::ensure_control_center_pin()` (рядом с `apps::ensure_own_pin`, флаг `cc_pin_added` в
`config.json`) и один раз дописывает пин, если его ещё нет — и новой установке, и панели,
сохранённой до появления кнопки. Дальше это личный выбор: снял галочку в меню «Виджеты на
панели» — кнопка больше не возвращается.

Правый клик по фону панели → «Центр управления» остался вторым путём, но он больше не
единственный: пункт меню — не кнопка, и найти шторку по нему было нельзя.

### Плашка

Шторка лежит на почти непрозрачной белой карточке (96,5 %) с тёмной рамкой 20 % и второй,
слабой рамкой внутри. Раньше карточка была белой на 62 % с рамкой 6 % — на окне приложения с
белым фоном шторка растворялась в нём вместе с заголовком. Плашки внутри (плитки, ползунки,
значки трея) тоже стали плотнее — 11 % вместо 6 % чёрного.

### Яркость

Ползунок показывает ровно то, что попросил пользователь, и ничего больше. Раньше каждый пиксель
движения отправлял в DDC/CI новую запись, а каждая запись на отдельном потоке ещё и читала
яркость обратно — очередь старых записей догоняла монитор, а ответ на чтение приходил с
задержкой, поэтому ползунок показывал 27 там, где экран стоял на 100. Теперь:

- значение-цель лежит в `AtomicU32` (`Hub::brightness_target`), запись идёт **одним** потоком
  (`brightness_busy` не даёт запустить второй), и этот поток крутится до тех пор, пока цель
  меняется, — всегда пишется самое новое число;
- после записи монитор **не** перечитывается: показанное значение — это запрошенное;
- чтение (`ask_brightness`) не запускается, пока идёт запись, а его ответ игнорируется, если
  запись началась, пока он ехал;
- если монитор не понимает DDC/CI (`set_brightness` вернул `false`), ползунок честно пишет
  «Not supported» вместо выдуманных процентов.

Закрывается по Esc, по клику вне шторки и при открытии Launchpad. Пока игра идёт в полном
экране, шторка прячется вместе с панелью.

Ночной свет — это тёплая гамма-кривая рабочего стола (`laminar_sys::night`): собственная кривая
пользователя запоминается при включении и возвращается при выключении. «Не беспокоить» пишет
`NOC_GLOBAL_SETTING_TOASTS_ENABLED` — тот же ключ, что и переключатель уведомлений в параметрах
Windows. Режим полёта выключает оба радио (Wi-Fi и Bluetooth) сразу.

## Полноэкранные приложения

Панель не должна висеть поверх игры или фильма. Раз в секунду (и на каждое событие
`EVENT_SYSTEM_FOREGROUND`) панель смотрит на окно на переднем плане: если оно видимо, не
свёрнуто, **не развёрнуто** (`IsZoomed`) и занимает весь монитор с допуском в 2 px, панель
прячется целиком (`SW_HIDE`) вместе с Launchpad, меню, превью и стеком. Развёрнутые окна
панель не прячут — они, как и панель задач, ходят под ней. Рабочий стол (`Progman`, `WorkerW`),
сама панель задач и окна AuraExplorer не считаются приложениями. Как только полноэкранное окно уходит
вперёд другое приложение — панель возвращается без активации (`SW_SHOWNOACTIVATE`).

Ключ `hide_fullscreen` (по умолчанию `true`) — переключатель «Поведение» → «Hide the panel in
full-screen apps».

## Панель и панель задач Windows

Панель резервирует себе полосу через appbar (`taskbar::appbar`) и садится на ту границу,
которую ей выделила Windows: `ABM_QUERYPOS` возвращает свободное место с учётом чужих appbar'ов,
`ABM_SETPOS` закрепляет его, а результат уходит в `Dock::floor_y`. Если панель задач Explorera
на экране, наша панель оказывается **над ней**; если панель задач скрыта
(`Hide the Windows Taskbar`) — на нижнем краю монитора, как раньше. От `floor_y` считаются окно
панели, шторка центра управления, подпись, превью, стек и зона выезда при автоскрытии, поэтому
всё это переезжает вместе с панелью.

## Язык виджетов

Месяцы, дни недели и порядок дней в календаре берутся из `strings::russian()`: русская панель
пишет «Ноябрь» и начинает неделю с понедельника, английская — «November» и с воскресенья.
Сокращения режутся по символам (`chars().take(3)`), а не по байтам: кириллица занимает по два
байта, и байтовый срез `&name[..3]` на ней паниковал.

## Погода

`laminar_sys::weather` тянет Open-Meteo (ключ не нужен). Клик по виджету открывает форму места
(`WAct::Connect("weather")`) — раньше любой клик уводил на msn.com, из-за чего виджет без данных
выглядел кнопкой-ссылкой. Пока данных нет, панель повторяет запрос каждые три минуты, а не раз в
полчаса, и `https_get` пробует три способа выхода в сеть: автоопределение прокси, прокси машины
и прямое соединение.

## Тема

`match_windows_theme` — «Стекло» → «Match Windows light/dark mode». Панель узнаёт о смене темы
по `WM_SETTINGCHANGE ("ImmersiveColorSet")`, запоминает это и перерисовывается на ближайшем тике
таймера, а не внутри нажатия, которым тему переключили: пересобираются значки, стекло, подпись,
часы, виджеты и Launchpad (он заново берёт тон стекла, сохраняя открытый раздел настроек).
Заодно панель повторно прячет панель задач Windows — Explorer на смене темы иногда показывает её
снова.

## Трей

Трей панели — апстримный: он перехватывает сообщения `Shell_TrayWnd`, показывает значки
сторонних приложений и передаёт их Explorer'у дальше, чтобы системный трей оставался полным,
когда панель не запущена. Это осознанное решение в пользу «как в Laminar»; отдельная
статус-зона с собственными индикаторами (из прежней версии дока) не переносилась.

## Обновления

Панель не обновляет себя: `updater::installed()` всегда `false`, поэтому обновление панели
происходит вместе с AuraUI-набором, а `begin_install()` предлагает запустить установщик AuraUI.
Проверка обновлений в настройках панели по умолчанию выключена — иначе панель полезла бы на
GitHub за версией, которой у неё нет.

## Сборка

```bash
cargo build -p aura-dock --release        # панель
cargo build -p aura-explorer --release        # файловый менеджер
cargo build -p aura-fences --bin Fences --release # сетки — самостоятельный бинарник
cargo build -p aura-service --release          # запуск компонентов
```

Набор собирает `scripts/package.ps1` по описанию `packaging/bundle.json` (раскладка,
`manifest.json`, проверка, zip); `aura.iss` собирает из этой же папки установщик.
GitHub Actions `Dock build` (`.github/workflows/dock-build.yml`) собирает пакеты, зовёт тот же
упаковщик, подписывает файлы и отдаёт артефакт `aura-dock-windows-x64` (и установщик отдельно).
Подробности — [packaging.md](packaging.md).

## Тесты

```bash
cargo test -p aura-dock          # на Windows: настройки, частоты проверок, апдейтер-заглушка
cargo test --workspace --exclude aura-dock --exclude laminar-sys
```

Переносимая логика AuraExplorer (конфиг, геометрия, каталог ярлыков) тестируется на хосте;
`aura-dock` собирается только под Windows.

## Ограничения

- Панель — второй процесс. Это выбрано сознательно: у апстрима свой dispatcher queue и
  STA-апартамент, и слияние в один процесс требует переделки его оконного цикла.
- Значки приложений и трей берутся из оболочки; в урезанных сборках Windows список может быть короче.
- Velopack-обновление и самообновление из меню отключены навсегда — это ответственность AuraExplorer.
