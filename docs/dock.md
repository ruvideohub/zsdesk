# Док ZSDesk (стиль macOS)

Док — отдельный компонент ZSDesk (`crates/zsdesk-dock`), который заменяет
работу с меню «Пуск»: закреплённые приложения, индикаторы запущенных окон,
сетка «Все приложения» с поиском, корзина и часы на одной панели внизу экрана.

Компонент намеренно сделан отдельным процессом и отдельным крейтом: он не
меняет поведение файлового менеджера и ячеек рабочего стола, а падение дока
не затрагивает ZSDesk.

```
crates/zsdesk-dock/
├── src/main.rs        точка входа, модули
├── src/app.rs         единственный экземпляр, DPI, COM, классы окон, цикл сообщений
├── src/dock.rs        окно дока: слоистое окно, отрисовка, мышь, меню, автозапуск
├── src/launcher.rs    оверлей «Все приложения» (сетка + поиск + клавиатура)
├── src/icons.rs       загрузка значков в отдельном потоке (IShellItemImageFactory)
├── src/winlist.rs     перечисление окон и действия над ними (активировать/свернуть/закрыть)
├── src/apps.rs        Shell-действия: запуск, показ в Проводнике, корзина, разбор .lnk
├── src/catalogue.rs   каталог ярлыков меню «Пуск» (тестируется без Windows)
├── src/model.rs       группировка окон по приложению, фильтр «это окно приложения?»
├── src/layout.rs      геометрия панели и слотов, смещение при автопрятании
├── src/magnify.rs     кривая увеличения (косинусный «колокол»)
├── src/config.rs      dock.json: закреплённые, внешний вид, атомарная запись
└── src/paths.rs       поиск папки профиля (portable / profile-location / APPDATA)
```

## Сборка

```powershell
cargo build -p zsdesk-dock --release            # target\release\zsdesk-dock.exe
```

Скопируйте `zsdesk-dock.exe` рядом с `ZSDesk.exe` (в тот же каталог пакета) и
запустите. Док — один экземпляр на сеанс (мьютекс `Local\ZSDesk.Dock`).

Аргументы:

| Аргумент | Значение |
|---|---|
| `--profile-dir <папка>` | использовать конкретный профиль ZSDesk (абсолютный путь) |
| `--help` | краткая справка |

Без аргументов папка профиля определяется так же, как у файлового менеджера:
`portable.flag` рядом с exe → `data\`, затем `profile-location.json`, иначе
`%APPDATA%\ZSDesk\`.

## Настройки (`dock.json`)

Файл лежит в папке профиля. Ошибка чтения не мешает запуску — берутся
значения по умолчанию, а запись атомарная (временный файл + `rename`).

```json
{
  "schema": 1,
  "pins": [
    { "path": "C:\\Windows\\explorer.exe", "target": "", "label": null },
    { "path": "C:\\ProgramData\\Microsoft\\Windows\\Start Menu\\Programs\\Code.lnk",
      "target": "C:\\Program Files\\Microsoft VS Code\\Code.exe", "label": "VS Code" }
  ],
  "magnification": true,
  "magnify_scale": 1.85,
  "magnify_influence": 2.5,
  "icon_size": 48.0,
  "autohide": false,
  "show_launcher": true,
  "show_trash": true,
  "show_clock": true,
  "show_status": true,
  "clock_24h": true
}
```

* `path` — что запускается (exe, `.lnk`, `shell:…`, `ms-settings:`).
* `target` — исполняемый файл за ярлыком; по нему док сопоставляет иконку с
  запущенными окнами. Пустое значение означает «совпадает с `path`».
* `label` — подпись вместо имени файла.
* `magnify_scale` ограничен 1.0–3.0, `magnify_influence` — 0.5–8.0,
  `icon_size` — 24–96: испорченный файл не сломает раскладку.
* `show_status` — индикаторы сети, звука и батареи на правом краю.

## Управление

| Действие | Результат |
|---|---|
| Наведение | увеличение иконок (если включено) + подпись над иконкой |
| Клик по не запущенному приложению | запуск |
| Клик по запущенному | переключение на его окно; если оно уже на переднем плане — сворачивание |
| Правый клик по иконке | список окон приложения, «Новое окно», «Закрепить/Убрать из дока», «Показать расположение файла», «Закрыть все окна» |
| Правый клик по фону дока | настройки: увеличение, автопрятание, часы, корзина, размер значков, автозапуск, папка профиля, выход |
| Иконка сетки | «Все приложения»: сетка плиток под размер экрана (3–10 × 2–6), поиск вводом, стрелки/Home/End, Enter, Esc, колесо — по страницам; счётчик «N / M» появляется только если всё не влезло |
| Иконка корзины | правый клик → «Очистить корзину», левый → открыть корзину |
| Шеврон и значок звука в зоне состояния | быстрые настройки Windows (`Win+A`) |
| Значок сети | `ms-availablenetworks:` — список сетей |
| Значок батареи | `ms-settings:batterysaver-settings` |
| Правый клик по индикатору | «Быстрые настройки», «Центр уведомлений», «Показывать индикаторы» |

Автопрятание оставляет внизу полосу 4 px: она видна всегда и вызывает док при
наведении. Прозрачные пиксели слоистого окна не перехватывают мышь, поэтому
окно может занимать всю ширину монитора, а панель остаётся компактной.

## Зона состояния (трей)

Справа от иконок, перед часами, стоит сектор индикаторов: шеврон «скрытые
значки», сеть, звук, батарея. Ширина сектора резервируется в раскладке
(`layout::place(..., reserve)`), поэтому панель растёт влево, а часы и правый
край остаются на месте. Сектор считается отдельным модулем `status.rs` и
покрыт тестами: правый край, отсутствие перекрытий, попадание кликов, пустой
сектор при `show_status: false`.

Откуда берутся значения (`tray.rs`):

| Индикатор | Источник | Поведение |
|---|---|---|
| Сеть | `InternetGetConnectedState` | точка гаснет, когда подключения нет |
| Звук | Core Audio, `IAudioEndpointVolume::GetMasterVolumeLevelScalar`/`GetMute` | значок меняется на «без звука» |
| Батарея | `GetSystemPowerStatus` | заливка по проценту, оранжевая при ≤ 20 % без питания, акцентная риска при зарядке; на настольном ПК — пустой контур |
| Часы | `GetLocalTime` | только текст, клика нет (формат переключается в меню) |

Эндпойнт звука создаётся один раз на потоке дока (`CoInitializeEx` +
`CoCreateInstance(MMDeviceEnumerator)`) и переиспользуется; опрос идёт раз в
секунду вместе с обновлением списка окон.

### Карточка «Звук и состояние»

Клик по шеврону или значку звука открывает карточку над доком (повторный клик
или клик мимо закрывает её):

* заголовок «Звук» и текущее значение справа;
* кнопка mute и ползунок громкости — тянется мышью, колесо не перехватывается,
  чтобы не мешать прокрутке под курсором;
* строки «Сеть» (подключено/отключено) и «Батарея» (процент и зарядка);
* четыре чипа: «Быстрые настройки» (`Win+A`), «Центр уведомлений» (`Win+N`),
  «Параметры звука», «Параметры сети».

Устройство: `panel.rs` — чистая геометрия и попадания (правый край, ряды чипов,
`volume_at`/`knob_x`, пять тестов), `panel_window.rs` — само окно класса
`ZSDesk.Dock.Panel`: слоистое, `WS_EX_NOACTIVATE`, без кражи фокуса. Клик мимо
определяется захватом мыши (`SetCapture`), `Esc` — опросом
`GetAsyncKeyState` в таймере, поэтому фокус у активного приложения остаётся.

Громкость пишется через `IAudioEndpointVolume::SetMasterVolumeLevelScalar` и
`SetMute` — тот же эндпойнт, что читает индикатор дока.

Про скорость: карточка рисуется только при изменении состояния (`dirty`),
значения перечитываются раз в 250 мс, таймер 16 мс живёт только пока карточка
открыта, никаких хуков и фоновых опросов нет. Док при этом не перерисовывается
вовсе — окно карточки отдельное.

**Почему здесь нет чужих значков трея.** Windows не даёт перечислить значки,
опубликованные другими программами: они уходят в `Shell_TrayWnd` explorer'а.
Единственный способ — чтение памяти explorer через `ToolbarWindow32`, и это
ровно тот путь, который Seelen UI прошёл и закрыл: 01.10.2025 модуль трея
удалён из проекта с формулировкой про «инъекции в системные процессы», а до
этого были «out of bounds read inside explorer.exe» и зависания панели от
занятого приложения. Поэтому индикаторы дока — свои, а клики открывают
системные панели, которые владеют настоящим треем.

**Что могло бы появиться дальше** (по желанию): своя карточка звука с
ползунком громкости, WinRT-уведомления со счётчиком и «режим оболочки» —
скрытие родной панели задач с резервированием места через `SHAppBarMessage`.
Последнее имеет смысл только вместе с уведомлениями: скрытая панель задач
уносит с экрана и настоящий трей.

## Реализация: важные детали

* Окно дока — `WS_EX_LAYERED | WS_EX_TOOLWINDOW | WS_EX_NOACTIVATE` на слое
  `HWND_TOPMOST`. Кадр рисуется общим Direct2D-таргетом
  (`zsdesk_windows::gfx`) и выдаётся через `UpdateLayeredWindow` — тем же
  способом, что и ячейки рабочего стола.
* Значки грузятся в отдельном потоке через `IShellItemImageFactory`
  (в 1.4× от размера на экране, чтобы увеличение не мылило), готовые
  `HBITMAP` передаются окну сообщением `WM_APP+501`.
* Док перерисовывается только при изменениях: 16-мс таймер ведёт анимацию
  увеличения и автопрятания, раз в секунду обновляются список окон, часы и
  тема системы.
* Список окон отбрасывает служебные оболочки (`Progman`, `WorkerW`,
  `Shell_TrayWnd`, …), cloaked-окна других виртуальных рабочих столов,
  tool-окна и диалоги, у которых есть владелец.
* Все подписи идут через `zsdesk_core::tr_format!` / `i18n::text`, ключи
  добавлены в `crates/zsdesk-core/resources/strings.en.json` вместе с
  русскими значениями — как и остальной перевод.

## Тесты

```bash
# Переносимая логика (конфиг, геометрия, группировка окон, каталог ярлыков):
cargo test -p zsdesk-dock            # 31 тест, работает и на не-Windows хосте
```

Тесты покрывают: кривую увеличения и её границы, раскладку (без перекрытий,
центрирование, сужение промежутков на узком экране, смещение при автопрятании),
фильтр окон, группировку по исполняемому файлу, приоритет закреплённых,
чтение/запись `dock.json` (включая испорченный файл и отсутствие временных
файлов), обход меню «Пуск» и поиск по каталогу приложений.

## Ограничения текущей версии

* Сопоставление с запущенными окнами идёт по пути исполняемого файла, поэтому
  упакованные (UWP/MSIX) приложения, запущенные без своего процесса, не
  подсвечиваются отдельной точкой — их можно закрепить как ярлык, но индикатор
  не появится.
* Положение — снизу по центру монитора, на котором находился курсор в момент
  запуска. Перетаскивания иконок для изменения порядка нет: порядок задаётся
  списком `pins` (или закреплением/откреплением через меню).
* Поиск в «Все приложения» принимает ввод с клавиатуры без IME-композиции:
  для русских/английских названий этого достаточно, ввод иероглифов через
  IME не поддерживается.
* Пункт «Пуск» и панель задач самой Windows док не отключает — это отдельная
  задача (Shell-замена), здесь реализована замена именно рабочего сценария.
* Значки трея сторонних приложений не показываются: они принадлежат explorer'у
  и недоступны через публичный API (подробности в разделе «Зона состояния»).

## Сборка в составе пакета

`scripts/package.ps1` собирает док вместе с приложением для каждой редакции:

```powershell
$dockFlags=@('build','--release','--locked','-p','zsdesk-dock','--manifest-path',(Join-Path $root 'Cargo.toml'))
& cargo @dockFlags --message-format=json-render-diagnostics 1>(Join-Path $WorkDir "cargo.dock.<edition>.current.jsonl")
```

Готовый `zsdesk-dock.exe` копируется в каталог пакета рядом с `ZSDesk.exe`;
манифест, ZIP и установщик Inno дополняются автоматически, потому что пункт
`Source: "{#SourceDir}\*"` уже копирует весь каталог рекурсивно. При
`-SkipBuild` док ищется рядом с `-BinaryPath`: если файла нет, скрипт
предупреждает и собирает пакет без дока, а не падает.

Готовые бинарники в `crates/zsdesk-dock/target` не нужны: путь `cargo` берёт из
общего рабочего каталога (`-p zsdesk-dock`), поэтому `--target-dir`
`scripts/package.ps1` сохраняется.
