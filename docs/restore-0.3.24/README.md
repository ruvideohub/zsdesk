# Восстановление правок 0.3.24

> **Архивный инструмент:** этот сценарий восстанавливает исторический вариант, а не
> актуальную версию проекта. Он не включает последующие исправления ZIP и сохранения
> настроек. Не запускайте его поверх действующего дерева: используйте Git и нужный
> коммит, иначе можно вернуть старые ошибки и затереть новые изменения.

Рабочее дерево иногда теряет `crates/` между сессиями. Здесь лежит всё, чтобы вернуть
правки правого щелчка на чистый `e159c18` одной командой:

```
git checkout -- crates/
python3 docs/restore-0.3.24/apply.py
```

Скрипт идемпотентен: второй прогон ничего не меняет. Файлы, где правок больше, чем можно
надёжно вписать заменой строк, переписываются целиком — `context_menu_common.rs`,
`context_menu_process.rs` (отдельно для explorer и fences: воркеры не идентичны),
`shell/menu.rs`, `desktop.rs`, `aura-ui/src/menus.rs`.

Проверить, что план строк жив, можно без Windows и без сборки приложения:

```
docs/restore-0.3.24/stand/run.sh   # 11 тестов
```

Стенд берёт `context_menu_common.rs` из дерева как есть и подменяет только три вещи,
которые модуль получает извне: `aura_core::i18n::text`, `ContextMenuOptions` и `MenuRow`.

Каталог остаётся в репозитории как запись о состоянии работы; удалить его вместе со
снятием надобности в восстановлении.
