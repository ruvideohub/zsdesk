# Виджеты на рабочем столе: как это должно работать

Сейчас на рабочем столе живёт ровно одна карточка — часы (`desktop_clock.rs`), и её положение
задано углом из настроек. Пользователь просит больше: любой виджет из каталога на рабочем столе,
перетаскивание и закрепление места. Это план того, как это сделать, не переписывая панель.

## Что уже есть

| Кусок | Где | Что умеет |
|---|---|---|
| Окно-карточка на рабочем столе | `desktop_clock.rs` | не topmost, `WS_EX_NOACTIVATE`, не забирает фокус, z-порядок под окном приложения |
| Перетаскивание | там же | тянется мышью, отпускание пишет позицию в настройки |
| Закрепление | `clock_locked` | перетаскивание выключается, меню работает |
| Меню карточки | `Dock::clock_menu` | угол/позиция, размер, формат времени, дата, секунды, скрыть |
| Движок виджетов | `widgets::{catalog,paint,render}` | 40+ виджетов, рисуются в `CompositionDrawingSurface` |
| Каталог и размеры | `widgets::catalog`, `Size::{Small,Medium,Large}` | имя, описание, категория, размер по умолчанию |

Чего не хватает: рендер произвольного виджета в окно рабочего стола, списка виджетов в
настройках, меню «добавить/убрать», и общего z-порядка для нескольких карточек.

## Устройство

Один новый модуль `desktop_widgets.rs` вместо `desktop_clock.rs`:

```rust
/// Одна карточка на рабочем столе: что рисуем, где, какого размера, закреплена ли.
struct Card {
    id: String,             // id из каталога: "clock", "weather-hourly", "month", …
    size: Size,             // Small / Medium / Large
    x: i32, y: i32,         // физические пиксели монитора
    locked: bool,
    // окно и поверхность — как у нынешних часов
    hwnd: HWND,
    surface: (u32, u32, f32, CompositionDrawingSurface),
    painted: Painted,       // кликабельные области внутри карточки
}

struct DesktopWidgets {
    cards: Vec<Card>,       // порядок = z-порядок
    monitor: RECT,
    scale: f32,
}
```

Ключевые решения:

1. **Рендер — тем же движком.** Карточка получает `CompositionDrawingSurface` нужного размера и
   вызывает `widgets::render(gfx, &surface, def, &ctx, w, h, scale, dense = false)`. `Ctx` уже
   собирается для панели и Launchpad (`dock_widgets.rs`), его достаточно передать сюда — значит
   погода, календарь, монитор ресурсов, «сейчас играет» и остальные работают на рабочем столе
   без отдельного кода.
2. **Клик внутри карточки — по её же `Painted`.** `widgets::render` возвращает `hits`, поэтому
   тап по плитке «Wi-Fi» на рабочем столе делает то же, что на панели (`WAct` уходит в
   `Dock::widget_act`).
3. **Z-порядок.** Все карточки — обычные (не topmost) окна, как часы: они лежат над обоями и под
   окнами приложений. Порядок между собой задаёт `cards`, перетаскивание поднимает карточку
   вверх списка. Раз в секунду — та же проверка «под окно на переднем плане», что уже есть в
   `keep_below()`.
4. **Перетаскивание и закрепление.** Логика часов переносится как есть: `WM_LBUTTONDOWN` берёт
   `SetCapture`, `WM_MOUSEMOVE` двигает окно с прижатием к монитору, `WM_LBUTTONUP` пишет позицию
   в настройки. При `locked` нажатие не начинает перетаскивание (меню по правому клику работает).
   Заголовок-«ручка» не нужен: тянется вся карточка, кроме мест, где `Painted` вернул действие.
5. **Настройки.** В `config.json`:

   ```json
   "desktop_widgets": [
     { "id": "clock",   "size": "large",  "x": 1620, "y": 60,  "locked": false },
     { "id": "weather-hourly", "size": "medium", "x": 120, "y": 900, "locked": true }
   ]
   ```

   `desktop_clock`, `clock_corner`, `clock_pos`, `clock_scale` и остальные ключи часов остаются:
   при первом запуске новой версии из них собирается одна карточка `clock` — панели, настроенные
   раньше, выглядят так же, как выглядели.
6. **Меню.** Правый клик по пустому месту карточки → «Size», «Lock Position», «Remove from
   Desktop»; правый клик по панели → раздел «Widgets on the Desktop» со списком восьми
   повседневных виджетов и галочками (как «Widgets on the Panel»). Добавление из каталога — через
   уже существующую галерею Launchpad, перетаскиванием на рабочий стол.

## Порядок работ

1. **Каркас** — `desktop_widgets.rs` с одной карточкой часов, `widgets::render` вместо ручной
   отрисовки, `desktop_widgets` в настройках и миграция из `clock_*`. Панель внешне не меняется.
2. **Несколько карточек** — список, z-порядок, добавление/удаление из меню панели, размеры S/M/L.
3. **Перетаскивание и закрепление** — уже отработано на часах, переносится на любую карточку.
4. **Сетка и привязка** — «прилипание» карточек друг к другу и к краям с шагом 8 px (Shift —
   без привязки), чтобы рабочий стол не превращался в свалку.
5. **Мониторы** — карточка помнит монитор (`monitor_device`), а не координаты: при смене
   раскладки экранов она остаётся на своём.

Шаги 1–2 — основная работа; 3 в основном перенос уже написанного, 4–5 — после того, как
заработает база.
