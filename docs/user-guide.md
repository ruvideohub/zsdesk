# AuraUI: краткое руководство

AuraUI содержит Dock, виджеты и Fences; системный Проводник Windows не заменяется.

## Запуск

После установки Dock по умолчанию запускается при входе в Windows. Внизу справа находится отдельный мини-док: видимые значки трея, стрелка остальных значков и кнопка центра управления. Левый и правый клики по значку передаются приложению. Виджеты рабочего стола запускаются Dock по включённым настройкам. Настройки Dock открываются через меню панели или ярлык **AuraDock Settings**. Если отключить автозапуск Dock, автоматически не поднимутся и его виджеты.

Fences открывается отдельно через меню «Пуск». При обычной установке его автозапуск выключен; включить его можно в настройках Fences. Это отдельный выбор пользователя.

## Сохранение настроек

Панель сохраняет настройки в `%APPDATA%\AuraExplorer\Dock\config.json`. Историческое имя каталога сохранено намеренно, чтобы не потерять существующие настройки. Удаление нового набора не удаляет пользовательские профили.

## Обновление со старой версии

**Автоматическое безопасное обновление старой версии AuraExplorer/AuraService пока не реализовано.** Не удаляйте старые exe или резервную запись интеграции до восстановления системного открытия папок. Сделайте резервную копию профилей и `%LOCALAPPDATA%\AuraUI`, а затем, используя старую версию, восстановите интеграцию и отдельно проверьте в Windows открытие папок, дисков, «Этот компьютер» и Win+E. Старый деинсталлятор может скрывать ошибки восстановления. Лишь после успешной проверки можно удалять прежнюю установку и ставить новую; если есть сомнения, обратитесь за помощью и сохраните старые файлы.
