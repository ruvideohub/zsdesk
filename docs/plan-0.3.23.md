# План 0.3.23 — что делаем и в каком порядке

Точка отсчёта: `cff25f4` (CI green, `AuraUI-0.3.22-x64.zip`). Дальше — доводим до продакшн
то, что уже есть, начиная с того, что мешает этим пользоваться каждый день.

## 1. Архиватор не замирает (сделано в этом раунде)

Сейчас упаковка и распаковка идут в потоке окна: на большом архиве окно перестаёт отвечать,
и человек не знает, работает программа или повисла.

- Работа уходит в отдельный поток; окно продолжает перерисовываться и принимать мышь.
- В строке состояния — полоса: определённая, когда известно число записей (распаковка,
  проверка, копирование), и бегущая, когда неизвестно (добавление, удаление).
- Пока идёт работа, повторный запуск действия не ставится в очередь, а отвечает
  «Подождите: идёт работа».
- Готовность сообщается сообщением окну, а не опросом из потока.

Приёмка: `AuraArc x` на архиве в сотни мегабайт — окно тянется за мышью, полоса движется,
по завершении строка состояния показывает итог, список перечитывается.

## 2. Несколько строк сразу (сделано в этом раунде)

Ссылка на скриншот заказчика говорит «Выбрано: 1 объект», но действия уже умеют работать с
набором имён.

- Ctrl+щелчок добавляет и убирает строку, Shift+щелчок выделяет диапазон, Ctrl+A — всё
  видимое; обычный щелчок сбрасывает выделение.
- «Копировать» и «Удалить» работают по всему выделению; выбранная папка уносит содержимое.
- Строка состояния считает выделение и его размер.

## 3. tar, tar.gz и gz (следующий раунд)

Самое частое, чего не хватает после `.zip`, и единственное, что можно сделать без чужих
библиотек: `flate2` уже есть.

- `.tar` — разбор заголовков ustar без записи на диск промежуточных файлов.
- `.tar.gz`, `.tgz` — тот же разбор поверх `GzDecoder`.
- `.gz` одиночного файла — распаковка рядом с исходным именем.
- Окно и консоль получают эти форматы через один и тот же движок; запись — пока только zip.

## 4. Устаревшая DLL перехвата (§11)

После обновления рядом с программой остаётся DLL прошлой версии. Нужно: своё имя сравнить с
тем, что лежит на диске, лишние — убрать, а если перехват не поднялся — сказать об этом
заметно, с одной кнопкой «Обновить перехват».

## 5. Сетки: фон, поиск внутри, бейджи

Из незакрытого по fences остаётся то, что видно каждый день: картинка-фон сетки, поиск
внутри сетки, значки-счётчики и подсказки при наведении.

## 6. Панель управления: вкладки

§9 шаг 4: «Компоненты / Интерфейс / Поиск / Ячейки / Виджеты / Интеграция» — после того, как
компоненты окончательно разъехались и у каждого есть свои настройки.

## Правило раунда

Коммитов — по одному на законченный кусок, а не по одному на правку: каждая сборка стоит
10–18 минут CI, поэтому в коммит складывается всё, что проверяется одной сборкой.
