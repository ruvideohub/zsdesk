ZSDesk — файловый менеджер с панелью в стиле macOS и сетками на рабочем столе.

Что в архиве
  ZSDesk.exe        файловый менеджер и рабочий стол: сетки, виджет часов, трей
  zsdesk-dock.exe   панель внизу экрана (её запускает и гасит сам ZSDesk)
  install.ps1       установка: копирует файлы, делает ярлыки и включает автозапуск
  install.cmd       то же двойным щелчком

Установка
  1. Распакуй архив целиком в любую папку.
  2. Запусти install.cmd (или install.ps1 правой кнопкой → «Выполнить с помощью PowerShell»).
  3. Готово: ZSDesk запускается сразу и будет запускаться сам при входе в Windows —
     сетки, часы и панель, без открытия окна, значок в трее.

Администратор не нужен: всё ставится в профиль пользователя
(%LOCALAPPDATA%\Programs\ZSDesk) и в HKCU.

Автозапуск
  ZSDesk.exe --desktop --tray — сетки и часы на рабочем столе, панель внизу, окно закрыто.
  Отдельная запись для панели не нужна: панель — дочерний процесс ZSDesk и живёт ровно
  столько же, сколько он. Если нужна только панель: install.cmd -PanelOnly
  Без автозапуска: install.cmd -NoAutostart

Удаление
  install.cmd -Remove   (останавливает ZSDesk, убирает автозапуск, ярлыки и папку)

Подпись
  Файлы подписаны самоподписанным сертификатом, поэтому SmartScreen может показать
  «Неизвестный издатель»: «Подробнее» → «Выполнить в любом случае». Проверить подпись:
  Get-AuthenticodeSignature .\ZSDesk.exe

Панель задач Windows скрывается на время работы ZSDesk и возвращается, когда он выходит.
Выход: правый клик по значку в трее → «Выход».
