AuraUI: Dock, виджеты рабочего стола и Fences.

  AuraDock.exe  панель и панель управления
  widgets.exe   виджеты, запускаются Dock
  Fences.exe    отдельные сетки рабочего стола (запуск вручную)
  install.cmd   установка в профиль текущего пользователя

Установка: распакуйте архив полностью и запустите install.cmd. По умолчанию только
Dock запускается при входе в Windows; виджеты поднимает Dock. Fences запускайте из
меню «Пуск». Fences также имеет собственный необязательный переключатель автозапуска.

ВАЖНО ПРИ ОБНОВЛЕНИИ: сначала удалите старую версию AuraExplorer/AuraService её
собственной программой после восстановления и проверки обработчиков папок.
Старый деинсталлятор может не сообщить об ошибке восстановления. До удаления
старых файлов сохраните профили и %LOCALAPPDATA%\AuraUI и проверьте Проводник.
Новая установка не удаляет старый проводник принудительно и не меняет его записи
реестра. Сохраните пользовательские профили. Затем установите новый комплект.
Если старые записи интеграции остались, исправьте их до установки.

Без автозапуска: install.cmd -NoAutostart
Без немедленного запуска: install.cmd -NoStart
Удаление: install.cmd -Remove. Пользовательские профили не удаляются.
