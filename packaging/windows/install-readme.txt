AuraExplorer — файловый менеджер с панелью в стиле macOS и сетками на рабочем столе.

Что в архиве
  auraservice.exe  служба запуска: она поднимает и держит остальные программы
  AuraExplorer.exe файловый менеджер
  AuraDock.exe     панель внизу экрана, Launchpad, контрол-центр
  fences.exe       сетки рабочего стола
  widgets.exe      виджеты рабочего стола (часы и карточка нагрузки)
  AuraArc.exe      архиватор: .zip из проводника AuraUI или из командной строки
  install.ps1       установка: копирует файлы, делает ярлыки и включает автозапуск
  install.cmd       то же двойным щелчком

Установка
  1. Распакуй архив целиком в любую папку.
  2. Запусти install.cmd (или install.ps1 правой кнопкой → «Выполнить с помощью PowerShell»).
  3. Готово: служба запускается сразу и будет запускаться сама при входе в Windows —
     она поднимает панель, сетки и часы, без открытия окна файлового менеджера.

Архиватор работает сам по себе — его можно скопировать отдельно от остального.
Двойной щелчок по AuraArc.exe (или запуск без аргументов) открывает окно: список содержимого,
«Открыть архив…», «Добавить файлы…», «Распаковать рядом», «Проверить»; файлы можно перетащить
на окно. Двойной щелчок по .zip при назначенном AuraArc тоже открывает окно с этим архивом.

Из командной строки:
  AuraArc a архив.zip Документы      добавить папку в архив
  AuraArc x архив.zip                распаковать рядом с архивом
  AuraArc l архив.zip                что внутри
  AuraArc t архив.zip                проверить

Администратор не нужен: всё ставится в профиль пользователя
(%LOCALAPPDATA%\Programs\AuraExplorer) и в HKCU.

Автозапуск
  auraservice.exe --run — одна запись на всё: служба сама поднимает панель, сетки и часы.
  Что именно запускать, решается в окне службы: «AuraUI - запуск и компоненты» в меню «Пуск»
  (auraservice.exe --settings). Там по переключателю на компонент и один переключатель
  «Запускать при входе в Windows». Прежние записи автозапуска отдельных программ установщик
  снимает сам.
  Без автозапуска: install.cmd -NoAutostart

Удаление
  install.cmd -Remove   (останавливает AuraExplorer, убирает автозапуск, ярлыки и папку)

Подпись
  Файлы подписаны самоподписанным сертификатом, поэтому SmartScreen может показать
  «Неизвестный издатель»: «Подробнее» → «Выполнить в любом случае». Проверить подпись:
  Get-AuthenticodeSignature .\AuraExplorer.exe

Панель задач Windows скрывается на время работы AuraExplorer и возвращается, когда он выходит.
Выход: правый клик по значку в трее → «Выход».
