AuraUI — комплект приложений Windows: AuraExplorer, AuraDock и Fences.

Что в архиве
  AuraExplorer.exe файловый менеджер и поиск
  Fences.exe       самостоятельные сетки рабочего стола и папок
  AuraDock.exe     панель внизу экрана и Launchpad
  widgets.exe      виджеты рабочего стола, запускаемые панелью
  auraservice.exe служба запуска и единое окно «Запуск и компоненты»
  install.ps1      установка для текущего пользователя
  install.cmd      установка двойным щелчком

Fences — отдельный процесс со своим профилем %APPDATA%\AuraFences. Он может мигрировать
старую раскладку, не запускает AuraExplorer или AuraDock, а команды «Открыть» передаёт
системному Проводнику Windows. Запустить его можно из меню AuraExplorer, ярлыка «Fences»
или напрямую через Fences.exe.

Установка
  1. Распакуй архив целиком.
  2. Запусти install.cmd (или install.ps1 правой кнопкой → «Выполнить с помощью PowerShell»).
  3. Программы устанавливаются в профиль пользователя (%LOCALAPPDATA%\Programs\AuraExplorer);
     администратор не нужен.

Автозапуск в комплекте AuraUI
  Одна запись при входе в Windows запускает auraservice.exe --run. Служба по переключателям
  окна «AuraUI — запуск и компоненты» запускает Fences, AuraDock и другие компоненты.
  Fences не получает отдельную запись автозапуска в этой установке — так не возникает
  второго владельца запуска. Чтобы запускать только Fences, используйте отдельный standalone
  Fences ZIP/installer и его собственную настройку входа.
  Без общей записи автозапуска: install.cmd -NoAutostart

Удаление
  install.cmd -Remove   (останавливает службу и приложения, убирает ярлыки и папку)
  Пользовательские настройки остаются в %APPDATA%.

Подпись
  Windows может показать предупреждение SmartScreen. Проверить подпись:
  Get-AuthenticodeSignature .\AuraExplorer.exe
